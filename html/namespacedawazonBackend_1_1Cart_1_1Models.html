enum dawazonBackend.Cart.Models.Status

Enumeración que representa los posibles estados de una línea de pedido en el sistema.

Define el ciclo de vida completo de una línea de carrito/pedido desde que se añade hasta que se completa o cancela. Cada estado representa una etapa del proceso de venta.

Ciclo de vida:

EnCarrito → Preparado → Enviado → Recibido
↘ Cancelado (desde cualquier estado)

Estado Descripción

Valores de enumeraciones
EnCarrito 

El producto está en el carrito del usuario, sin completar la compra.

Este es el estado inicial cuando un usuario añade un producto a su carrito. El producto no está reservado ni comprometido hasta que se realiza el pago.

Preparado 

El pedido está siendo preparado por el vendedor/manager.

Indica que el manager ha aceptado o está procesando el pedido. En este estado se verifica el stock y se prepara para el envío.

Enviado 

El pedido ha sido enviado al cliente.

El producto está en tránsito hacia la dirección del cliente. Puede estar asociado a un número de seguimiento.

Recibido 

El cliente ha recibido el pedido correctamente.

Estado final exitoso. Indica que el pedido fue entregado y el cliente lo recibió conforme.

Cancelado 

El pedido ha sido cancelado.

Puede cancelarse desde cualquier estado. Puede ser solicitado por:

  • El cliente antes de recibir el producto
  • El manager por falta de stock
  • Sistema por timeout de pago
