Descripción detallada

Data Transfer Object (DTO) que representa una línea de venta dentro de un carrito de compras.

Este DTO contiene información detallada sobre un producto específico incluido en un carrito, incluyendo precios, cantidades, estado del pedido, y datos del cliente y manager asociados.

Ciclo de vida de una línea de carrito:

  1. Status.EnCarrito - El producto está en el carrito del usuario
  2. Status.Preparado - El pedido está siendo preparado por el vendedor
  3. Status.Enviado - El pedido ha sido enviado al cliente
  4. Status.Recibido - El cliente ha recibido el pedido
  5. Status.Cancelado - El pedido ha sido cancelado

Uso típico:

Se utiliza como elemento dentro de la colección CartResponseDto.CartLines para mostrar el contenido completo de un carrito de compras.
