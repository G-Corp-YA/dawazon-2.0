Data Transfer Object (DTO) que representa la respuesta completa de un carrito de compras.

Este DTO es un record que contiene toda la información de un carrito de compras, incluyendo el identificador, usuario, estado de compra, información del cliente, líneas de productos, y totales.

Características:

  • Inmutable: Como record, una vez creado no puede ser modificado.
  • Igualdad por valor: Dos instancias con los mismos valores son iguales.
  • Conciso: Utilza la sintaxis primaria constructor para definir propiedades.

Uso típico:

Se utiliza como respuesta en los endpoints de API del módulo de carrito:

  • GET /cart/{id} - Obtener un carrito específico
  • GET /cart/user/{userId} - Obtener carrito de un usuario
  • GET /cart/all - Listar carritos con filtros
Parámetros
IdString único que identifica el carrito (ejemplo: "CART-2024-001").

Este identificador se genera automáticamente al crear el carrito y se utiliza para todas las operaciones subsecuentes.

Parámetros
UserIdIdentificador numérico del usuario en el sistema.

Relaciona el carrito con el usuario que lo creó y es propietario.

Parámetros
PurchasedTrue si el carrito ha sido comprado (pagado), False si está activo.

Cuando un carrito se compra, se marca como Purchased = true y se crea un pedido formal. Los carritos comprados no pueden ser modificados.

Parámetros
ClientInstancia de ClientDto con la información de envío.

Contiene la dirección de envío, teléfono y email del cliente. Se cumplimenta cuando el usuario finaliza la compra.

Parámetros
CartLinesLista de objetos SaleLineDto representando cada producto.

Cada línea representa un producto diferente en el carrito con su cantidad, precio y estado. La lista puede estar vacía si el carrito no tiene productos.

Parámetros
TotalItemsEntero que representa la suma de cantidades de todas las líneas.

Se calcula sumando la propiedad Quantity de cada línea en CartLines. Es útil para mostrar badges o indicadores de número de artículos.

Parámetros
TotalDecimal con el precio total incluyendo descuentos e impuestos.

Se calcula sumando TotalPrice de todas las líneas del carrito. Este es el amount que el usuario deberá pagar al comprar.

Data Transfer Object (DTO) utilizado para filtrar, paginar y ordenar consultas de carritos de compras.

Este DTO es un record que define los parámetros de búsqueda y paginación cuando se listan carritos desde la API o desde el panel de administración.

Uso típico:

Se utiliza como parámetro de consulta en endpoints como:

  • GET /cart/all - Listar todos los carritos con filtros
  • GET /cart/manager/{managerId} - Listar carritos de un manager

Valores por defecto:

  • Page = 0 (primera página)
  • Size = 10 (10 elementos por página)
  • SortBy = "id" (ordenar por ID)
  • Direction = "asc" (orden ascendente)
Parámetros
ManagerIdIdentificador numérico del manager o null para no filtrar.

Cuando se proporciona, solo retorna los carritos asignados o procesados por el manager especificado. Útil para el panel de administración.

Parámetros
IsAdminTrue para incluir todos los carritos del sistema, false para filtrar por usuario.

Cuando es true, se ignoran las restricciones de usuario y se muestran todos. Requiere que el usuario tenga permisos de administrador.

Parámetros
PurchasedTrue para solo carritos comprados, false para solo activos, null para todos.

Permite separar carritos activos (en proceso) de historicos (ya comprados).

Parámetros
PageEntero indicando la página a recuperar. Por defecto 0 (primera página).

Se combina con Size para implementar paginación. La primera página es 0.

Parámetros
SizeEntero con el número de elementos a devolver. Por defecto 10.

Controla el tamaño de la página de resultados. Valores típicos: 10, 25, 50, 100.

Parámetros
SortByString con el nombre del campo de ordenación. Por defecto "id".

Campos comunes: "id", "total", "createAt", "updateAt", "purchased".

Parámetros
Direction"asc" para orden ascendente, "desc" para orden descendente.

Por defecto es ascendente (a-z, 0-9).
