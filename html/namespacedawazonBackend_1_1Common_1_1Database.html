class dawazonBackend.Common.Database.DawazonDbContext ( DbContextOptions< DawazonDbContext >  options)

DbContext principal para la aplicación Dawazon.

Hereda de IdentityDbContext para integrar autenticación de ASP.NET Core. Configura las entidades del dominio, relaciones, y datos iniciales (seeding).

Características:

  • Hereda de IdentityDbContext para gestión de usuarios y roles
  • Entidades: Products, Categories, Carts
  • Owned Types: Client y Address
  • Seed data para desarrollo y testing

Configura el modelo de datos: relaciones, índices, conversiones y datos iniciales.

Configuraciones realizadas:

  1. User.Client y User.Client.Address: Ownership anidado
  2. User.ProductsFavs: Conversión JSON
  3. Product.Images: Conversión JSON
  4. Product.Comments: Tabla separada ProductComments
  5. Product.Version: Token de concurrencia (optimistic locking)
  6. Cart.Client y Cart.Client.Address: Ownership anidado
  7. Cart.CartLines: Tabla separada con clave compuesta
Parámetros
modelBuilderConstructor de modelos de EF Core.

DbSet para la tabla de Productos.

DbSet para la tabla de Categorías.

DbSet para la tabla de Carritos de compra.

Sembrado de datos iniciales para pruebas y desarrollo.

Datos sembrados:

  • 3 Categorías: Figuras, Comics, Ropa
  • 13 Productos de ejemplo
  • 2 Carritos: uno comprado (CART00000001) y uno activo (CART00000002)
  • Clientes y direcciones asociados
  • Líneas de ejemplo
