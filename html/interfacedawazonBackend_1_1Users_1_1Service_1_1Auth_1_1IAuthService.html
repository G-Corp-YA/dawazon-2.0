Descripción detallada

Interfaz que define el contrato para el servicio de autenticación de usuarios.

Proporciona métodos para el registro e inicio de sesión de usuarios en el sistema.

Características:

  • Registro de nuevos usuarios
  • Inicio de sesión con credenciales
  • Generación de tokens JWT

Uso típico:

IAuthService authService = httpContext.RequestServices.GetRequiredService<IAuthService>();
// Registro
var registerDto = new RegisterDto { Username = "john", Email = "john@example.com", Password = "password123" };
var signUpResult = await authService.SignUpAsync(registerDto);
// Inicio de sesión
var loginDto = new LoginDto { UsernameOrEmail = "john", Password = "password123" };
var signInResult = await authService.SignInAsync(loginDto);

◆ SignInAsync()

Task< Result< AuthResponseDto, UserError > > dawazonBackend.Users.Service.Auth.IAuthService.SignInAsync ( LoginDto  dto)

Inicia sesión con credenciales de usuario (username o email + password).

Parámetros
dtoObjeto LoginDto con las credenciales de acceso.
Devuelve
Un Result<AuthResponseDto, UserError> que puede ser:
  • Exitoso: contiene AuthResponseDto con el token JWT
  • Fallido: contiene un UserError indicando el error

Proceso de login:

  1. Busca el usuario por username o email
  2. Valida la contraseña usando Identity
  3. Genera un nuevo token JWT

Errores posibles:

  • UnauthorizedError: Si el usuario no existe o la contraseña es incorrecta

Nota: El método sanitiza el input eliminando caracteres de salto de línea.

var loginDto = new LoginDto
{
UsernameOrEmail = "juan@example.com", // o puede ser el username
Password = "SecurePassword123"
};
var result = await authService.SignInAsync(loginDto);
if (result.IsSuccess)
{
var token = result.Value.Token;
Console.WriteLine($"Login exitoso. Token: {token}");
}
else
{
Console.WriteLine($"Error: {result.Error.Message}");
}

◆ SignUpAsync()

Task< Result< AuthResponseDto, UserError > > dawazonBackend.Users.Service.Auth.IAuthService.SignUpAsync ( RegisterDto  dto)

Registra un nuevo usuario en el sistema.

Parámetros
dtoObjeto RegisterDto con los datos de registro del usuario.
Devuelve
Un Result<AuthResponseDto, UserError> que puede ser:
  • Exitoso: contiene AuthResponseDto con el token JWT
  • Fallido: contiene un UserError indicando el error

Proceso de registro:

  1. Valida que el username y email no estén en uso
  2. Crea el usuario en Identity con hash de contraseña
  3. Asigna el rol "User" por defecto
  4. Crea un carrito de compras vacío
  5. Genera un token JWT de autenticación

Errores posibles:

  • UserConflictError: Si el username o email ya existen
  • UserError: Si falla la creación del usuario en Identity
var registerDto = new RegisterDto
{
Username = "juan Perez",
Email = "juan@example.com",
Password = "SecurePassword123"
};
var result = await authService.SignUpAsync(registerDto);
if (result.IsSuccess)
{
var token = result.Value.Token;
Console.WriteLine($"Usuario registrado. Token: {token}");
}
else
{
Console.WriteLine($"Error: {result.Error.Message}");
}
