record dawazonBackend.Common.Error.DomainError ( string  Message)
abstract

Record abstracto base para errores de dominio en la aplicación.

Este record sirve como base para todos los errores del dominio. Utiliza el patrón Result para manejo funcional de errores.

Uso:

Se combina con CSharpFunctionalExtensions.Result<T, TError> para retornar errores de forma segura en lugar de lanzar excepciones.

Ejemplo de uso:

public Task<Result<CartResponseDto, DomainError>> GetByIdAsync(string id)
{
var cart = await _repository.FindByIdAsync(id);
if (cart == null)
return Result.Failure<CartResponseDto, DomainError>(
new CartNotFoundError($"Carrito con ID {id} no encontrado"));
return cart.ToDto();
}
