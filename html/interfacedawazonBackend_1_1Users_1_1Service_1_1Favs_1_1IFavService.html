Descripción detallada

Interfaz que define el contrato para el servicio de gestión de productos favoritos.

Proporciona métodos para administrar los productos favoritos de los usuarios.

Características:

  • Añadir productos a favoritos
  • Eliminar productos de favoritos
  • Obtener lista de favoritos con paginación

Uso típico:

IFavService favService = httpContext.RequestServices.GetRequiredService<IFavService>();
// Añadir a favoritos
var addResult = await favService.AddFav("product123", userId);
// Obtener favoritos paginados
var filters = new FilterDto { Page = 0, Size = 10, SortBy = "name" };
var favsResult = await favService.GetFavs(userId, filters);

Añade un producto a la lista de favoritos del usuario.

Parámetros
productIdEl identificador único del producto a añadir.
userIdEl identificador único del usuario.
Devuelve
Un Result<bool, DomainError> que puede ser:
  • Exitoso: true si se añadió correctamente
  • Fallido: un DomainError indicando el error

Errores posibles:

  • UserNotFoundError: Si el usuario no existe
  • UserHasThatProductError: Si el producto ya está en favoritos
  • UserError: Si falla la actualización del usuario

Nota: No se permiten productos duplicados en la lista de favoritos.

var result = await favService.AddFav("PROD-001", 123);
if (result.IsSuccess)
{
Console.WriteLine("Producto añadido a favoritos");
}

Task< Result< PageResponseDto< ProductResponseDto >, DomainError > > dawazonBackend.Users.Service.Favs.IFavService.GetFavs ( long  userId,
FilterDto  pageable 
)

Obtiene la lista de productos favoritos del usuario con paginación.

Parámetros
userIdEl identificador único del usuario.
pageableObjeto FilterDto con los filtros de paginación y ordenamiento.
Devuelve
Un Result<PageResponseDto<ProductResponseDto>, DomainError> que puede ser:
  • Exitoso: PageResponseDto<ProductResponseDto> con los productos favoritos
  • Fallido: un DomainError indicando el error

Campos de ordenamiento soportados:

  • "name" - Ordenar por nombre del producto
  • "price" - Ordenar por precio
  • "stock" - Ordenar por cantidad en stock
  • cualquier otro valor - Ordenar por ID (comportamiento por defecto)

Valores por defecto:

  • Si Page < 0: se usa 0
  • Si Size <= 0: se usa 10
var filters = new FilterDto
{
Page = 0,
Size = 20,
SortBy = "price",
Direction = "asc"
};
var result = await favService.GetFavs(userId, filters);
if (result.IsSuccess)
{
foreach (var product in result.Value.Content)
{
Console.WriteLine($"- {product.Name}: {product.Price}€");
}
}
