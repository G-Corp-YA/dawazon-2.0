Descripción detallada

Interfaz que define el contrato para extraer información de tokens JWT.

Proporciona métodos para extraer diferentes partes de información de un token JWT sin necesidad de validar la firma.

Características:

  • Extracción de ID de usuario
  • Extracción de rol
  • Verificación de rol de administrador
  • Extracción de email
  • Extracción de todos los claims
  • Validación de formato de token

Uso típico:

IJwtTokenExtractor extractor = httpContext.RequestServices.GetRequiredService<IJwtTokenExtractor>();
var token = httpContext.Request.Headers["Authorization"].ToString().Replace("Bearer ", "");
var userId = extractor.ExtractUserId(token);
var isAdmin = extractor.IsAdmin(token);
var userInfo = extractor.ExtractUserInfo(token);

Valida el formato básico del token JWT sin verificar la firma.

Parámetros
tokenToken a validar.
Devuelve
true si el formato es válido, false en caso contrario.

Validaciones:

  • No estar vacío
  • Tener 3 partes separadas por puntos
  • Header y payload no estar vacíos

También detecta tokens con algoritmo "none".

{
return BadRequest("Token inválido");
}
