Descripción detallada

Interfaz que define el contrato para el servicio de generación y validación de tokens JWT.

Proporciona métodos para crear y verificar tokens de autenticación JWT.

Características:

  • Generación de tokens JWT firmados
  • Validación de tokens JWT
  • Extracción de información del usuario

Configuración requerida en appsettings.json:

"Jwt": {
"Key": "tu-clave-secreta-minimo-32-caracteres",
"Issuer": "DawazonApi",
"Audience": "DawazonApi",
"ExpireMinutes": 60
}

◆ GenerateTokenAsync()

Task< string > dawazonBackend.Users.Service.Jwt.IJwtService.GenerateTokenAsync ( User  user)

Genera un token JWT firmado con la información del usuario.

Parámetros
userUsuario para el cual generar el token.
Devuelve
Una cadena que representa el token JWT generado.

Claims incluidos en el token:

  • Sub: ID del usuario
  • Name: Nombre del usuario
  • Email: Correo electrónico del usuario
  • Role: Rol del usuario
  • Jti: Identificador único del token

Configuración:

El token se genera con los valores de configuración:

  • Issuer: Configurable (default: "TiendaApi")
  • Audience: Configurable (default: "TiendaApi")
  • Expiration: Configurable en minutos (default: 60)
  • Algorithm: HMAC-SHA256
Excepciones
InvalidOperationExceptionSe lanza si la clave JWT no está configurada en appsettings.json.
var user = await userManager.FindByNameAsync("john");
var token = await jwtService.GenerateTokenAsync(user);
// token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

◆ ValidateToken()

string? dawazonBackend.Users.Service.Jwt.IJwtService.ValidateToken ( string  token)

Valida un token JWT y extrae el nombre de usuario.

Parámetros
tokenToken JWT a validar.
Devuelve
El nombre de usuario contenido en el token, o null si el token es inválido.

Validaciones realizadas:

  • Firma del token
  • Issuer
  • Audience
  • Fecha de expiración

Nota: El método retorna null en caso de cualquier error de validación, incluyendo token expirado, firma inválida, o formato incorrecto.

var token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...";
var username = jwtService.ValidateToken(token);
if (username != null)
{
Console.WriteLine($"Token válido para usuario: {username}");
}
else
{
Console.WriteLine("Token inválido o expirado");
}
