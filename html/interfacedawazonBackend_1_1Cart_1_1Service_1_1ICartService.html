Descripción detallada

Interfaz que define el contrato para el servicio de gestión de carritos de compra, ventas y procesamiento de pedidos.

Esta interfaz define todas las operaciones de negocio relacionadas con el módulo de carrito, incluyendo gestión de productos en el carrito, checkout, procesamiento de pagos con Stripe, y administración de ventas.

Patrón de diseño:

Utiliza el patrón Service que encapsula la lógica de negocio. Las operaciones retornan Result<T, TError> para manejar errores de forma funcional.

Principios aplicados:

  • Single Responsibility: Solo maneja lógica de carrito y ventas
  • Dependency Inversion: Los controladores dependen de esta abstracción
  • Error Handling: Usa Result pattern para manejo de errores

Dependencias externas:

  • Repository.ICartRepository - Acceso a datos
  • Products.Repository.Productos.IProductRepository - Gestión de productos
  • Stripe.IStripeService - Procesamiento de pagos
  • Common.Mail.IEmailService - Envío de emails
  • UserManager<User> - Gestión de usuarios
