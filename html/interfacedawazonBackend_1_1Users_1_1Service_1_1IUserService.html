Descripción detallada

Interfaz que define el contrato para el servicio de gestión de usuarios.

Esta interfaz proporciona métodos para administrar usuarios en el sistema, incluyendo operaciones de lectura, actualización, banneo y estadísticas.

Características principales:

  • Listado paginado de usuarios con filtros
  • Obtención de usuario por ID
  • Actualización de perfil de usuario
  • Banneo de usuarios (borrado lógico)
  • Estadísticas de usuarios

Uso típico:

// Inyectar el servicio
IUserService userService = httpContext.RequestServices.GetRequiredService<IUserService>();
// Obtener usuarios paginados
var filters = new FilterDto { Page = 0, Size = 10, SortBy = "nombre" };
var users = await userService.GetAllAsync(filters);
// Obtener usuario por ID
var userResult = await userService.GetByIdAsync("123");
if (userResult.IsSuccess)
{
var user = userResult.Value;
}

Task dawazonBackend.Users.Service.IUserService.BanUserById ( string  banUserId)

Desactiva (bannea) a un usuario estableciendo la bandera de borrado lógico.

Parámetros
banUserIdEl identificador único del usuario a banear.
Devuelve
Una tarea asíncrona que representa la operación.

Esta operación realiza un borrado lógico, estableciendo la propiedad IsDeleted del usuario a true. El usuario no será eliminado de la base de datos pero no aparecerá en las consultas regulares.

Nota: Esta operación no elimina los datos asociados del usuario (como pedidos, comentarios, etc.).

// Banear usuario por ID
await userService.BanUserById("12345");

◆ GetAllAsync()

Task< PageResponseDto< UserDto > > dawazonBackend.Users.Service.IUserService.GetAllAsync ( FilterDto  filters)

Obtiene una lista paginada de usuarios filtrados según los criterios especificados.

Parámetros
filtersObjeto FilterDto que contiene los filtros de búsqueda, paginación y ordenamiento.
Devuelve
Una tarea que representa la operación asíncrona. El resultado es un PageResponseDto<UserDto> que contiene:
  • Lista de usuarios en la página actual
  • Total de páginas disponibles
  • Total de elementos
  • Información de paginación

Este método excluye automáticamente los usuarios eliminados (IsDeleted = true). Los filtros soportados incluyen:

  • Page: Número de página (0-indexed)
  • Size: Tamaño de página
  • SortBy: Campo de ordenamiento (actualmente solo "nombre")
  • Direction: Dirección del ordenamiento ("asc" o "desc")
var filters = new FilterDto
{
Page = 0,
Size = 20,
SortBy = "nombre",
Direction = "asc"
};
var result = await userService.GetAllAsync(filters);
Console.WriteLine($"Total usuarios: {result.TotalElements}");
foreach (var user in result.Content)
{
Console.WriteLine($"- {user.Nombre} ({user.Email})");
}

◆ GetByIdAsync()

Task< Result< UserDto, UserError > > dawazonBackend.Users.Service.IUserService.GetByIdAsync ( string  id)

Obtiene un usuario específico por su identificador único.

Parámetros
idEl identificador único del usuario (tipo long como string).
Devuelve
Un Result<UserDto, UserError> que puede ser:
  • Exitoso: contiene el UserDto del usuario encontrado
  • Fallido: contiene un UserError indicando el error

El método utiliza el patrón Result de CSharpFunctionalExtensions para manejar errores. Si el usuario no se encuentra, retorna un UserNotFoundError.

var result = await userService.GetByIdAsync("12345");
if (result.IsSuccess)
{
Console.WriteLine($"Usuario encontrado: {result.Value.Nombre}");
}
else
{
Console.WriteLine($"Error: {result.Error.Message}");
}

Actualiza los datos de un usuario existente, incluyendo su información de perfil, dirección y opcionalmente su imagen de avatar.

Parámetros

userRequestDtoObjeto UserRequestDto con los nuevos datos del usuario.
imageArchivo de imagen opcional para actualizar el avatar del usuario.
Devuelve
Un Result<UserDto, UserError> que puede ser:
  • Exitoso: contiene el UserDto con los datos actualizados
  • Fallido: contiene un UserError indicando el error

Esta operación actualiza los siguientes campos:

  • Nombre del usuario
  • Correo electrónico
  • Teléfono (si se proporciona)
  • Dirección completa (calle, ciudad, provincia, código postal)
  • Avatar (si se proporciona una imagen)

Errores posibles:

  • UserNotFoundError: Si el usuario no existe
  • UserUpdateError: Si falla la actualización o la subida de imagen
