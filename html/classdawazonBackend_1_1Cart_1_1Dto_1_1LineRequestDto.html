Descripción detallada

Data Transfer Object (DTO) utilizado para solicitudes de modificación de líneas de carrito.

Este DTO se utiliza en las solicitudes HTTP (POST/PUT) para actualizar o añadir líneas de productos en un carrito de compras.

Uso típico:

  • POST /cart/line - Añadir una nueva línea al carrito
  • PUT /cart/line - Actualizar una línea existente
  • PATCH /cart/line - Modificar el estado de una línea

Estados posibles:

Status enum define los estados del ciclo de vida del pedido.
